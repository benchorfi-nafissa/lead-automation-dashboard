# Lead Automation Dashboard

A personal AI-assisted lead management and workflow automation project.

## Problem

Small businesses often receive customer requests through forms, email or messaging platforms. Without a centralized process, leads can be missed and follow-ups can be forgotten.

## Planned solution

This application will:

1. Receive a new lead.
2. Validate the submitted data.
3. Store the lead in PostgreSQL.
4. Classify its priority and category.
5. Send a notification.
6. Create a follow-up reminder.
7. Display the lead in a dashboard.

## Planned architecture

Form or webhook  
→ Backend API  
→ PostgreSQL  
→ AI classification  
→ Notification and follow-up  
→ Dashboard

## Planned stack

- Node.js
- Express.js
- PostgreSQL
- React
- n8n
- REST API
- Optional AI integration
